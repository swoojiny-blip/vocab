# 한자 연습장

천자문(1,000자)과 한국어문회 3급(1,817자) 한자를 획순을 보며 아이패드에서 쓰는 연습장입니다.

## 자료 출처
- 획순: [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data) (Make Me a Hanzi 기반, Arphic Public License — `ARPHICPL.TXT` 참조)
- 급수별 한자·훈음: [rycont/hanja-grade-dataset](https://github.com/rycont/hanja-grade-dataset) (원자료 저작권은 한국어문회에 있음)
- 천자문 훈음: 직접 입력(오류가 있을 수 있음)
- 사자성어 500개: 직접 정리한 목록(한자·독음은 한국어문회 훈음 자료와 자동 대조, 뜻풀이는 직접 작성 — 오류가 있을 수 있음)

## 기기별 안내
- 아이패드: Safari → 공유 → 홈 화면에 추가
- 갤럭시(폰/탭): Chrome → 메뉴(⋮) → 홈 화면에 추가(앱 설치)
- 학습 기록은 기기마다 따로 저장됩니다. 기기 간 이동은 목록 → 백업·복원을 이용하세요.
